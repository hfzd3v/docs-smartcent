# Overview

Welcome to **SmartCent** — the invoice and payment management platform built for Malaysian businesses.

## What is SmartCent?

SmartCent helps you:

- Create and send invoices
- Collect payments via FPX, Stripe, and more
- Manage instalment plans
- Generate e-invoices compliant with LHDN requirements
- Track payment status in real time

## Getting Started

1. Set up your organisation
2. Add your contacts (customers/clients)
3. Create your first invoice
4. Share the payment link
